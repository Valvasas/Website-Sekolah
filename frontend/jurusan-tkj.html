Infrastruktur Jaringan

Administrasi Server

Membangun dan mengelola web server, database, DNS, dan mail server menggunakan sistem operasi berbasis Linux (Debian/Ubuntu)

Keamanan Jaringan

Mempelajari implementasi Firewall, enkripsi data, manajemen bandwidth, serta teknik dasar penetrasi untuk mengamankan jaringan komputer

Daftar Jurusan Ini

Level 1: Pengenalan Hardware dan Software Komputer (Kelas X)

Mengenal lebih dalam ke komponen hardware dan software komputer, mengenal internet dan sistem jaringan, dan dasar-dasar troubleshooting

Level 2: Routing, Switching dan pengenalan Jaringan Internet (Kelas XI)

Konfigurasi VLAN, perutean statis/dinamis (OSPF, BGP) di MikroTik, instalasi kabel Ethernet (RJ45), Pembuatan Topologi di Cisco Packet Tracer, dan pengelolaan WLAN (Hotspot)

Level 3: Konfigurasi topologi jaringan mandiri dengan alat alat praktik TKJ (Kelas XII)

Pembuatan sistem jaringan mandiri mulai dari pembuatan kabel sampai ke konfigurasi beberapa alat networking lengkap dengan ip dan servernya, ujian tes Kompetensi, dan Praktik Kerja Lapangan (PKL)
